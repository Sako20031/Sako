# Nerja Moto Rent — сайт проката скутеров Honda в Нерхе

Одностраничный сайт на ES/EN: каталог скутеров, калькулятор аренды, форма заявки и
готовое сообщение в WhatsApp (`wa.me/34638000001`). Бэкенда нет — всё считается в браузере,
данные клиента нигде не сохраняются.

Стек: Vite + React 18 + TypeScript (strict), обычный CSS с токенами, иконки lucide-react,
шрифты Fraunces + Inter (самостоятельно размещённые, без Google Fonts).

## Запуск

```bash
cd NerjaMoto
npm install
npm run dev            # http://localhost:5173
npm test               # юнит-тесты: даты, цены, сообщение WhatsApp, валидация
npm run build          # продакшн-сборка → dist/
npm run build:single   # один самодостаточный файл → dist-single/index.html (для превью)
```

Для продакшна задайте адрес сайта — тогда появятся canonical, hreflang, og:image и sitemap.xml:

```bash
SITE_URL=https://ваш-домен.es npm run build
```

Vercel: новый проект, Root Directory `NerjaMoto`, переменная окружения `SITE_URL`.

## Где что менять

| Что | Файл |
|---|---|
| Контакты, адрес, часы, ссылки Google Maps / отзывов, рейтинг | `src/config/business.ts` |
| Модели, цены, скидки за длительность, правила расчёта | `src/config/rental.ts` |
| Плашки доверия, преимущества, FAQ, направления | `src/config/content.ts` |
| Картинки (сейчас — иллюстрации) | `src/config/media.ts`, `src/assets/media/` |
| Тексты интерфейса ES / EN | `src/i18n/es.ts`, `src/i18n/en.ts` |
| Цвета, шрифты | `src/styles/base.css` → `:root` |
| Логика цены / сообщения WhatsApp | `src/lib/pricing.ts`, `src/lib/whatsapp.ts` |

Иллюстрации генерируются скриптом `node scripts/build-art.mjs`; OG-картинка и иконка —
`node scripts/build-og.mjs`.

**Фото скутеров:** положите фото именно этой модели в `src/assets/photos/`, импортируйте
и укажите в поле `photo` модели в `rental.ts`. Подпись «иллюстрация» исчезнет сама.
