# LUMIÈRE CEILINGS — сайт натяжных потолков

Премиальный сайт-шоурум с конфигуратором потолка и админ-панелью.
Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Postgres (Neon).

## Что есть

- **Главная**: большой первый экран (фото меняется в админке), коллекция, «Студия потолка», как мы работаем, портфолио, доверие, FAQ.
- **Коллекция** (`/catalog`): 10 решений, фильтры по категории и помещению, подробная карточка с выбором цвета и света → «Добавить в мой проект».
- **Калькулятор** (`/calculator`):
  1. несколько комнат (копировать, переименовать, удалить);
  2. форма: прямоугольная, Г-образная (габариты + вырез или две части без двойного счёта), с выступами, с нишами, своя форма — редактор контура по точкам (перетаскивание пальцем, добавление/удаление углов, точные длины стен) или ввод без рисования;
  3. технические детали (углы считаются по форме комнаты, трубы, стояки, ниши, примыкания, «Не знаю — помогите определить»);
  4. покрытие (с проверкой совместимости со светом);
  5. освещение; 6. цвет, температура, карниз, доп. услуги; 7. итог.
  - Живой расчёт: панель справа на компьютере, нижняя панель + шторка на телефоне.
  - Проект сохраняется в браузере (без имени и телефона), печать/PDF, скачивание описания, WhatsApp, заявка на замер.
- **Портфолио**, **О компании**, **FAQ**, **Контакты** (заявка на замер), **Политика** (шаблон), **404**, страницы районов `/rayony/…` (только для районов, введённых в админке).
- SEO: заголовки и описания, canonical, Open Graph-картинка, `sitemap.xml`, `robots.txt`, FAQ-разметка, LocalBusiness — только когда указаны реальные телефон и адрес.

## Админ-панель

Адрес **`/admin`** (ссылка «Вход» внизу сайта). PIN по умолчанию **`0000`** — смените его во вкладке «Безопасность».

| Вкладка | Что можно |
|---|---|
| Заявки | все заявки, звонок/WhatsApp в одно нажатие, статусы, состав проекта, сумма, пересчитанная сервером |
| Цены | режим цен (выключены / примерные / цены компании), монтаж, минимальный заказ, высокие потолки, скидка, покрытия, профили, свет, доп. работы, карнизы, цвета, услуги |
| Работы | добавить/изменить/удалить работу, обложка и галерея (фото уменьшаются перед загрузкой), «Проект» или «Концепт», публикация |
| Главный экран | фоновое фото (загрузить, ссылка, вернуть исходное), фокус кадра для телефона, тексты, преимущества |
| Каталог | включить/выключить решения, тексты, фото, цена «от» |
| Контакты | бренд, телефон, WhatsApp, e-mail, адрес, часы, районы, реквизиты, гарантия, валюта |
| Тексты и FAQ | вопросы-ответы, «О компании», этапы работы, блок доверия |

Изменения появляются на сайте сразу после «Сохранить». «Вернуть исходное» сбрасывает раздел.

Безопасность: PIN хранится на сервере как scrypt-хеш, сессия — случайный токен в httpOnly-cookie (SameSite=Strict), блокировка на 15 минут после 8 неверных попыток, проверка Origin на изменяющих запросах.

## Цены

Сейчас включены **примерные цены** (`config/pricing.ts`): каждая сумма на сайте помечена «пример цен». Это не цены компании. Введите свои в админке → «Цены» и выберите режим «Цены компании». Пустое поле = «уточнит специалист». В режиме «Выключены» сайт пишет: «Предварительный расчёт будет доступен после настройки цен компании».

Формула: покрытие + монтаж + профиль + освещение + элементы + доп. работы + доплата до минимального заказа − скидка. Движок — `lib/pricing.ts`, геометрия — `lib/geometry.ts`, оба без UI; при заявке сервер пересчитывает сумму сам.

## Запуск

```bash
cd Lumiere
npm install
npm run dev        # http://localhost:3000
```

Без базы локально всё хранится в папке `.data/` (админка, фото, заявки работают).

Проверки: `npm run typecheck`, `npm run lint`, `npm test` (геометрия и цены, включая сценарий 5×4 → 20 м²/18 м и 4×3 → 12 м²/14 м), `npm run build`.

## Деплой на Vercel

1. Vercel → Add New → Project → репозиторий `Sako20031/Sako` → **Root Directory: `Lumiere`** → Deploy.
2. Storage → Create Database → **Neon (Postgres)** → Connect to project (добавится `POSTGRES_URL`). Можно подключить уже существующую базу — у сайта свои таблицы `lumiere_*`.
3. Redeploy. Таблицы создаются сами при первом запросе.
4. Открыть `/admin`, войти с `0000`, сменить PIN, заполнить контакты и цены.

Без базы на Vercel сайт работает на встроенном содержимом, но админка не сохраняет изменения, а форма заявки предлагает WhatsApp/телефон.

## Переменные окружения

См. `.env.example`: `POSTGRES_URL` (или `DATABASE_URL`), `ADMIN_PIN` (необязательно — начальный PIN вместо 0000), `NEXT_PUBLIC_SITE_URL` (адрес сайта для canonical/sitemap), `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` (необязательно — копия заявок в Telegram; код написан, но с реальным ботом не проверялся).

## Что должна предоставить компания

Телефон, номер WhatsApp, e-mail, адрес, часы работы, районы работы, юридическое название и БИН, условия гарантии, настоящие цены, фото реальных работ, реальные отзывы и сертификаты (если есть), подтверждённый порядок работы, текст политики конфиденциальности.

## Фотографии

Примеры фото — со стока Unsplash (лицензия Unsplash), подписаны как иллюстрации, а не выполненные объекты. Загружаются напрямую с `images.unsplash.com`. Если какое-то фото недоступно, вместо него показывается аккуратная нарисованная заглушка. Любое фото заменяется в админке.

## Казахский язык

Тексты контента лежат в `config/*` и редактируются в админке; интерфейсные строки — в компонентах. Для версии `/kz`: вынести строки компонентов в словарь, добавить сегмент `app/(site)/kz/…` и поля `*_kz` в контент.
