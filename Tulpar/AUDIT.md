# TULPAR — аудит и чек-лист запуска

Сайт проверен скриншотами Playwright на десктопе (1440×900) и мобильном (390×844).
Ошибок в консоли нет.

## 6. Что выглядело дёшево и что исправлено

| Приоритет | Проблема (первая версия) | Исправление |
|---|---|---|
| Высокий | Камера слишком близко: автомобиль обрезан, выглядел «игрушкой во весь экран» | Все ракурсы отодвинуты на ~35%. Автомобиль занимает 45–55% кадра, как на студийной съёмке |
| Высокий | При переходе между секциями камера пролетала сквозь кузов | Интерполяция по дуге (радиус отдельно) + запрет входить в габарит машины |
| Высокий | Пол отражал золотой софтбокс огромным пятном, кадр «грязный», был виден край пола | Пол матовый, отражения окружения 0.12, туман прячет горизонт |
| Высокий | Пересвеченные блики на стекле с bloom выглядели как артефакты | Софтбоксы приглушены, порог bloom 0.92, стекло темнее |
| Средний | Заголовки «Выберите», «Почувствуйте» обрезались маской строки | Отдельный кегль для узких панелей |
| Средний | Мелкий текст шоурума терялся на золотом рефлексе | Затемняющий градиент под панелями (контраст ≥ 4.5:1) |
| Средний | На телефоне чёрная машина сливалась с фоном и была крошечной | Выше экспозиция, кадр смещён вверх, дистанция под портретный экран |

### Что поднимет проект ещё выше (следующие шаги)

1. **Настоящая 3D-модель** реального автомобиля из наличия (GLB, 2–5 МБ, Draco)
   вместо процедурного концепт-купе. Это даст самый большой прирост «вау».
   Модель покупается на Sketchfab или TurboSquid или заказывается у 3D-моделлера.
2. **Фото реального салона и реальных авто** в карточках коллекции, в стиле
   тёмной студии, как сцена.
3. **Настоящие данные:** адрес, телефон, WhatsApp, цены, цифры (сейчас это
   правдоподобные заглушки).
4. **Звук** (по желанию): тихий звук двигателя при наведении на «Тест-драйв».

## 7. Финальный аудит

| Область | Статус | Комментарий |
|---|---|---|
| Визуал | ✅ | Единая палитра, 2 шрифта, золото только как акцент |
| Сторителлинг | ✅ | Легенда → доверие → вовлечение → выбор → снятие возражений → CTA |
| 3D-рендеринг | ✅ | PBR, clearcoat, студийное окружение PMREM, ACES |
| Плавность | ✅ | Демпфирование камеры, Lenis, только `transform`/`opacity` в CSS |
| Адаптивность | ✅ | 390 / 860 / 1100 / 1440, горизонтальный скролл → список на мобильном |
| Доступность | ✅ | Skip-link, семантика, `aria-*`, фокус, `prefers-reduced-motion`, весь текст в HTML |
| SEO | ✅ | title/description/OG, `lang="ru"`, JSON-LD `AutoDealer`, один `h1` |
| Вес | ✅ | JS 52 КБ gzip (основной) + 137 КБ gzip (3D, грузится отдельно), шрифты ~150 КБ |
| FPS | ⚠️ | Проверено в программном рендере. На реальном устройстве нужно проверить iPhone 12+ и средний Android |
| Браузеры | ⚠️ | Chromium проверен. Safari и Firefox нужно посмотреть вручную до запуска |
| Без WebGL | ✅ | Градиентная заглушка, сайт полностью читается |
| Форма | ⚠️ | Отправка через WhatsApp, без сервера. Номер нужно вписать в `src/main.js` → `CONFIG` |

## Чек-лист запуска

- [ ] Вписать реальные телефон, WhatsApp, e-mail в `src/main.js` (`CONFIG`)
- [ ] Вписать адрес и часы в футер и JSON-LD в `index.html`
- [ ] Заменить цены и цифры на реальные
- [ ] Проверить на iPhone (Safari) и Android (Chrome): плавность, форма, меню
- [ ] Подключить домен (например, `tulpar.kz`) в Vercel
- [ ] Добавить `og:image` (скриншот hero 1200×630)
- [ ] Подключить аналитику (Яндекс Метрика или GA4) и цель «отправка формы»
- [ ] Политика обработки персональных данных (ссылка под формой)
