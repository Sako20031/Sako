# TULPAR — концепция 3D-сайта автосалона

## 1. Визуальное направление

**Идея.** Тулпар — крылатый конь из степных легенд. Он несёт героя быстрее ветра.
Сайт не говорит «у нас много машин». Он говорит «мы найдём автомобиль с характером
Тулпара». Поэтому главный герой страницы — один автомобиль в тёмной студии, а не
каталог с фотографиями.

**Нарратив.** Ночь, студия, свет.
1. Темнота, и из неё проявляется силуэт.
2. Свет скользит по кузову.
3. Камера обходит машину, как покупатель в салоне.
4. Финал: автомобиль смотрит прямо на зрителя, фары горят, рядом форма записи на тест-драйв.

**Чего мы избегаем.** Стоковых фото с бликами, слайдеров-каруселей, неона «как у
всех», синего корпоративного цвета, кнопки «Подробнее» под каждой карточкой.

| Слой | Решение |
|---|---|
| Палитра | Ночной графит `#08090B`, тёплый чёрный `#111214`, степное золото `#C9A45C` (только акценты), холодное серебро `#C9CDD2` (текст), гранат `#B3262C` (задний свет) |
| Типографика | **Unbounded**: широкий гротеск для заголовков, читается как «скорость». **Manrope**: спокойный текст. Заголовки крупные, с плотным трекингом. Подписи капсом, разрядкой, мелким кеглем, как техническая маркировка |
| Материалы | Автоэмаль с лаком (clearcoat), тонированное стекло-зеркало, матовая резина, сатиновый металл дисков |
| Свет | Студийные софтбоксы-полосы. Их отражения рисуют линии на кузове. Одна тёплая золотая полоса — подпись бренда |
| Атмосфера | Золотые частицы «степного ветра» летят вдоль кузова, скорость зависит от скорости скролла |
| Глубина | Fixed WebGL-сцена за контентом. Текст лежит над ней слоями, поэтому секции «проезжают» мимо автомобиля |
| Камера | Длиннофокусная (FOV 30–35°), как у автомобильного фотографа: без искажений, медленные проезды, низкая точка съёмки |
| Эмоция | Тишина → уважение → желание сесть за руль |

**Знак.** Три пера, сложенные в крыло. Оно же читается как три полосы скорости.

Секции 5–7 приглушают сцену, чтобы текст оставался главным. 3D работает там, где
продаёт эмоцию, и уходит в фон, где нужна информация.

**Доступность и адаптивность.**
- Весь текст в HTML, а не в canvas.
- `prefers-reduced-motion` отключает плавный скролл, движение камеры и частицы.
- Есть фокус-стили, `aria-label` у иконок, контраст текста не ниже 4.5:1.
- На мобильном горизонтальный скролл превращается в вертикальный список, плотность пикселей снижается, bloom выключен.
- Без WebGL остаётся градиентная сцена и SVG-силуэт.

## 4. Система движения

- **Скролл.** Lenis (lerp 0.1). Камера не привязана к таймлайну жёстко. У каждой
  секции свой ключевой кадр (позиция, цель, сдвиг кадра, приглушение). Переход
  идёт на протяжении экрана, пока следующая секция въезжает (`smoothstep`). Потом
  реальная камера догоняет цель с демпфированием (≈4/с), поэтому движение не
  бывает рваным даже при резком скролле.
- **Камера.** Проезды по дуге вокруг авто, высота от 0.6 до 2.2 м. В Hero к
  позиции добавляется ±0.25 м параллакса от курсора.
- **Объект.** В шоуруме кузов вращается перетаскиванием с инерцией. Вне шоурума
  он плавно возвращается в исходное положение. Смена цвета — интерполяция за 0.8 с.
- **Свет.** Задний световой бар и передние ходовые огни разгораются, когда камера
  смотрит на них.
- **Частицы.** Скорость ветра = базовая + скорость скролла.
- **Текст.** Строки заголовков выезжают из-под маски (`translateY 110% → 0`,
  0.9 с, `cubic-bezier(.2,.7,0,1)`). Манифест подсвечивается пословно, со scrub.
- **Закреплённые секции.** Манифест (sticky, 250vh), сервисы (pin с горизонтальным
  сдвигом).
- **Hover.** Карточки чуть поднимаются, золотая линия растёт слева направо.
  Кнопки получают заливку снизу вверх.
- **Easing.** Выезды: `expo.out`. Scrub: `none`. Камера: экспоненциальное демпфирование.
- **Производительность.** Анимируются только `transform` и `opacity`. Рендер
  останавливается, когда вкладка скрыта. DPR ≤ 1.75 (на мобильном ≤ 1.25).
  Геометрия процедурная, без загрузки моделей.

## 5. Этапы сборки

1. **Каркас.** Vite + ванильный JS (без фреймворка: один экран, максимум скорости).
   Шрифты лежат локально (латиница и кириллица).
2. **Разметка.** Семантичные секции, весь контент в HTML, SEO-мета, JSON-LD `AutoDealer`.
3. **Дизайн-система.** Токены цвета, шкала типографики через `clamp()`, сетка 12 колонок.
4. **3D-сцена.**
   - Рендерер (ACES, sRGB) и студийное окружение через PMREM из сцены с софтбоксами.
   - Пол с контактной тенью.
   - Автомобиль: экструзия бокового профиля + деформация (сужение в плане, завал
     боковин), стеклянный купол, колёса, светотехника.
5. **Хореография камеры.** Ключи по секциям, демпфирование, параллакс.
6. **Взаимодействия.** Шоурум (drag, цвета), форма тест-драйва.
7. **Анимации интерфейса.** Маски строк, манифест, счётчики, горизонтальный скролл.
8. **Оптимизация.** Bloom только на десктопе, пауза рендера, адаптивный DPR, reduced-motion.
9. **Проверка.** Скриншоты десктоп и мобильный (Playwright), консоль без ошибок, аудит (`AUDIT.md`).
10. **Деплой.** Vercel, проект с корнем `Tulpar/`, `npm run build` → `dist`.
