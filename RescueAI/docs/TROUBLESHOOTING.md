# Частые проблемы

| Симптом | Причина и решение |
|---|---|
| «ИИ-анализ сейчас недоступен» | `RESCUE_AI_PROVIDER=none` или нет ключа. Это ожидаемое честное состояние. См. AI_PROVIDERS.md. |
| ИИ доступен для симптомов, но не для фото | `RESCUE_AI_EXTERNAL_IMAGES_AUTHORIZED=false` (по умолчанию). |
| Статус `failed`, код `provider_unreachable` | сервер не может достучаться до api.anthropic.com: проверьте исходящий доступ/прокси. |
| `provider_auth_failed` | неверный ключ. |
| `job_lost_or_timed_out` | сервер перезапустился во время анализа; повторите. |
| Вход не держится / 401 после входа | открываете по http в production (cookie `Secure`) или фронтенд и API на разных доменах (`SameSite=Strict`). Отдавайте `frontend/dist` с бэкенда. |
| 403 `csrf_header_missing` | клиент не отправил `x-rescue-client: 1`. |
| `RuntimeError`/`ValueError` при старте в production | не задан сильный `RESCUE_SECRET_KEY` или `RESCUE_COOKIE_SECURE=true`. |
| Не открывается камера в PWA | нужен HTTPS; разрешите камеру для сайта в «Настройки iOS → Safari → Камера». |
| Фото HEIC не принимается | при выборе из галереи Safari обычно конвертирует в JPEG; если нет — в «Настройки → Камера → Форматы» выберите «Наиболее совместимый». |
| Офлайн-справочник пропал | iOS очищает данные редко открываемых сайтов. Загрузите снова в «Настройках». |
| Диктовка не работает | Web Speech API в Safari работает не везде; используйте микрофон на клавиатуре iOS. |
| `npx playwright test` не находит браузер | укажите `PW_CHROMIUM=/путь/к/chrome`. |
| Тесты бэкенда медленные | поставьте `RESCUE_BCRYPT_ROUNDS=4` только для тестов (уже сделано в conftest). |
