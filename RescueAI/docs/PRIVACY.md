# Конфиденциальность и данные

Соответствие законодательству РК о персональных и медицинских данных **не оценивалось**.
Ниже — что и где хранится по факту реализации.

## Где хранятся данные

| Данные | Где | Срок |
|---|---|---|
| Карта вызова (жалоба, витальные, анамнез, `patient_ref`) | БД сервера | до удаления пользователем или администратором |
| Анализы (контекст, ответ ИИ, проверки) | БД сервера | `RESCUE_RETENTION_DAYS` (по умолчанию 30), затем удаляются задачей очистки |
| Оригиналы снимков | приватный каталог сервера, только если отмечено «Сохранить оригинал» | как у анализа; удаляются вместе с вызовом или по сроку |
| Копия для анализа | только в памяти сервера на время запроса | не хранится |
| Аудит | БД сервера: кто, когда, какое действие, ID объекта; без клинического текста | не удаляется автоматически |
| Телефон: язык, тема, метаданные офлайн-пакета | localStorage | до очистки |
| Телефон: офлайн-справочник (протоколы, препараты, правила) | Cache Storage | до удаления в настройках |
| Телефон: данные пациентов | **не хранятся** (только в памяти открытого экрана) | — |

Следствие: при отсутствии сети карта вызова не сохраняется (показывается предупреждение).
Офлайн-черновики с шифрованием не реализованы.

## Передача внешним сервисам

Только ИИ-провайдер, и только когда он настроен. Состав данных — в [AI_PROVIDERS.md](AI_PROVIDERS.md).
Изображения — только при `RESCUE_AI_EXTERNAL_IMAGES_AUTHORIZED=true`. Аналитики и трекеров нет.

## Удаление

- Пользователь удаляет свой вызов: удаляются вызов, анализы, проверки, документация, файлы.
- Администратор запускает очистку по сроку хранения.
- Деидентификация для исследований не реализована.

## Экран в приложении

«Настройки → Конфиденциальность» кратко описывает то же самое на трёх языках.
