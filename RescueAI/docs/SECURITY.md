# Безопасность

## Реализовано

- Пароли: bcrypt (12 раундов). Вход ограничен 10 попытками в минуту с одного IP.
- Сессия: JWT в cookie `httpOnly`, `SameSite=Strict`, `Secure` в production, срок 12 ч (смена).
  Токен недоступен JavaScript.
- CSRF: все изменяющие запросы требуют заголовок `x-rescue-client: 1` (кросс-сайтовая форма
  не может его поставить) плюс `SameSite=Strict`.
- Роли: `paramedic` (только свои вызовы), `admin` (справочник, пользователи, очистка),
  `auditor` (журнал аудита, только чтение). Чужие вызовы возвращают 404.
- Загрузки: тип по сигнатуре содержимого (заявленный MIME игнорируется), Pillow `verify`,
  лимит пикселей против decompression bomb, лимит размера (15 МБ) в middleware и в обработчике,
  PDF: проверка структуры, шифрования, числа страниц. EXIF удаляется из копии для анализа.
- Хранилище: случайные имена, права 0600, защита от выхода за каталог.
- Ошибки: ответы валидации содержат только поле и тип ошибки, без присланных значений;
  необработанные исключения — `internal_error` без деталей.
- Заголовки: `nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`,
  `Permissions-Policy`, `Cache-Control: no-store` для API. Swagger отключён в production.
- Секреты только в окружении; запуск в production с ключом по умолчанию запрещён.
- Ограничение частоты анализов на пользователя; идемпотентные ключи загрузок.
- Аудит: вход/выход, неудачные входы, создание/чтение/изменение/удаление вызовов, анализы,
  проверки, скачивание оригиналов, изменения справочника, очистка.

## Не реализовано / известные ограничения

- Ограничитель частоты — в памяти процесса (не работает между экземплярами).
- Нет смены пароля и сброса пароля через интерфейс, нет MFA, нет блокировки аккаунта.
- Нет отзыва сессии до истечения (logout удаляет cookie на устройстве; украденный токен
  действует до конца срока). Для production — серверный список сессий.
- Нет антивирусной проверки файлов (снижено строгой проверкой форматов и перекодированием).
- CSP не задана (рекомендуется `default-src 'self'; img-src 'self' blob:; worker-src 'self' blob:`).
- Шифрование БД и хранилища на уровне диска — задача инфраструктуры.
- Независимый аудит безопасности и тест на проникновение не проводились.
