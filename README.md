## /ayaulym — сайт для Аяулым 💖

Открывается по адресу `/ayaulym` (или `/love`). Кабинет администратора — замочек 🔒
внизу страницы или `/ayaulym#admin`. PIN по умолчанию: `0000` (сменить можно в
кабинете, вкладка «Пароль»).

В кабинете: фото в галерею (загрузить / подписать / удалить), комплименты для
кнопки-сердечка, голосовые (запись прямо с телефона или загрузка файла до ~3 МБ),
аватарка, тексты письма и приглашения.

Всё хранится в базе Vercel Postgres (Neon, подключена к проекту `sako`), в отдельных таблицах `love_*`. Комплименты по умолчанию — в `public/ayaulym-files/content.json`.
Код: `public/ayaulym.html`, `app/api/love/[...path]/route.js`, `lib/love.js`.

## /quest — квест для Аяулым 🐾

Открывается по адресу `/quest` (начать заново — `/quest#restart`). Милый персонаж Мими
ведёт по локациям, переходы — анимация лапок. Локации: дата 25.11.25 из цифр → любимая
кафешка (Биси) → поймай 10 сердечек → игра «найди пары» → собрать слово «АЯУЛЫМ» → кто первый влюбился (шутка с сальто) → пазл из первого совместного фото (11.09.2025) →
кодовый замок с датой больницы → «Что я сказал?» (голосовое задом наперёд, появится, когда задан `voice`) → пицца желаний (купоны) → письмо и стиралка с подсказкой, где подарок (`giftHint`).

Код — один файл `public/quest.html`, всё настраивается в объекте `CONFIG` вверху скрипта:
фото (`public/quest-files/first.jpg`, `hospital.jpg`), подписи, дата больницы (`hospitalDate`).
