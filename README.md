## /ayaulym — сайт для Аяулым 💖

Открывается по адресу `/ayaulym` (или `/love`). Кабинет администратора — замочек 🔒
внизу страницы или `/ayaulym#admin`. PIN по умолчанию: `0000` (сменить можно в
кабинете, вкладка «Пароль»).

В кабинете: фото в галерею (загрузить / подписать / удалить), комплименты для
кнопки-сердечка, голосовые (запись прямо с телефона или загрузка файла до ~3 МБ),
аватарка, тексты письма и приглашения.

Всё хранится в базе Vercel Postgres (Neon, подключена к проекту `sako`), в отдельных таблицах `love_*`. Комплименты по умолчанию — в `public/ayaulym-files/content.json`.
Код: `public/ayaulym.html`, `app/api/love/[...path]/route.js`, `lib/love.js`.

## /tumar — TUMAR Heritage

Лендинг ювелирного ателье с казахскими медальонами: каталог с фильтрами, корзина,
оформление заказа, подписка, подбор тұмара (квиз). Открывается по адресу `/tumar`.

Кабинет администратора — замочек 🔒 внизу страницы, `/tumar/admin` или `/tumar#admin`.
PIN по умолчанию: `0000` — **смените сразу** (вкладка «Настройки»). После 8 неверных
попыток вход блокируется на 15 минут.

В кабинете:
- **Заказы** — все заказы с сайта (имя, телефон, WhatsApp, город, комментарий, состав,
  сумма), статус «Новый / В работе / Выполнен / Отменён», удаление.
- **Товары** — добавить, изменить (название, цена, вес, металл, описание, значок, тираж,
  фильтры), загрузить фото или выбрать рисунок, скрыть, поменять порядок, удалить.
- **Тексты** — любой текст на странице (заголовки, кнопки, отзывы, контакты, символы,
  квиз, сообщения) с поиском и кнопкой «↺ исходный».
- **Подписчики** — e-mail из формы клуба, копирование списка, удаление.

Всё хранится в той же базе Vercel Postgres, в отдельных таблицах `tumar_*`. Каталог по
умолчанию — `public/tumar-files/content.json` (копируется в базу при первом запуске).
Цены в заказе всегда считает сервер. Код: `public/tumar.html`,
`app/api/tumar/[...path]/route.js`, `lib/tumar.js`.
