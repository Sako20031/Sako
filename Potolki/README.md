# Натяжные потолки Уральск — лендинг

Сайт для @natyaznye_potolki_uralsk. Один файл `index.html`, без сборки.

## Что поменять перед запуском (блок `CONFIG` в конце `index.html`)
- `whatsapp` — номер владельца, только цифры (`77XXXXXXXXX`), `phoneDisplay` — как показывать.
- `pricePerM2` — цена за м² «от–до» (сейчас 500–670 ₸, т.е. 60 м² ≈ 30–40 тыс. ₸).
- `types[].k` — множитель цены для каждого вида потолка; `extras` — светильники, люстры, трубы, минимальный заказ.
- `works` — фото работ из папки `works/`.

## Как работает заявка
Форма (имя, номер, город, адрес, тип, цвет, размеры + расчёт калькулятора) открывает WhatsApp
владельца с готовым сообщением. Хозяин сам отвечает клиенту с точной ценой.

## Деплой
Vercel → New Project → этот репозиторий → Root Directory: `Potolki`, Framework: Other.
