# TUMAR Heritage

Сайт ювелирного ателье TUMAR: медальоны и тұмары с казахской символикой.
Три языка (қазақша / русский / English), каталог, корзина, заказы, подписка,
поиск, квиз и кабинет администратора.

Отдельный проект Next.js в папке `Tumar/` со своей базой данных PostgreSQL.

## Запуск на Vercel (один раз)

1. **Создать проект.** Vercel → Add New → Project → импортировать репозиторий
   `Sako20031/Sako` → в поле **Root Directory** выбрать `Tumar` → Deploy.
2. **Подключить базу.** В проекте: Storage → Create Database → **Neon (Postgres)**
   → регион Frankfurt (ближе к Казахстану) → Connect to project.
   Vercel сам добавит переменную `POSTGRES_URL`.
3. **Redeploy** (Deployments → ⋯ → Redeploy).
4. Открыть `/admin`, войти с PIN `0000` и **сразу сменить PIN** (Настройки).
   Во вкладке «Настройки» должно быть «База данных: подключена ✓».

Таблицы создаются автоматически при первом запросе, каталог заполняется из
`public/tumar-files/content.json`. Структура базы — в [`db/schema.sql`](db/schema.sql).
Свой домен: Settings → Domains.

## Языки

- Переключатель KZ / RU / EN в шапке и в мобильном меню; выбор запоминается.
  Ссылка на нужный язык: `/?lang=kz`, `/?lang=en`.
- Первое посещение: язык браузера (казахский → KZ, английский → EN, иначе RU).
- Переводы интерфейса — `public/tumar-files/i18n.js` (ключ — русский текст).
- Товары переводятся в кабинете: вкладки «Русский / Қазақша / English» в карточке товара.
  В списке товаров видно, где не хватает перевода.

## Кабинет администратора

Адрес `/admin` (или замочек 🔒 внизу сайта). После 8 неверных PIN — блокировка на 15 минут.

- **Заказы** — имя, телефон, WhatsApp, город, комментарий, состав, сумма, язык клиента;
  статусы «Новый / В работе / Выполнен / Отменён»; удаление.
- **Товары** — добавить, изменить, перевести, фото или рисунок, скрыть, порядок, удалить.
- **Тексты** — любой текст сайта на каждом из трёх языков, поиск, «↺ исходный».
- **Отзывы** — добавить, изменить, удалить, порядок, звёзды, переводы KZ/EN; нет отзывов — блок скрыт.
- **Подписчики** — список e-mail, копирование, удаление.
- **Настройки** — контакты (телефон, WhatsApp, e-mail; нажатие на номер предлагает позвонить
  или написать в WhatsApp), фон главного экрана: видео (по умолчанию `public/tumar-files/hero.mp4` —
  юрты и лошади; можно удалить, заменить своим MP4 до 3 МБ или ссылкой, вернуть стандартное),
  яркое видео с белым текстом или полупрозрачное, нарисованная анимированная степь;
  состояние базы, смена PIN, выход.

## Моушн-анимация бренда

12-секундный ролик: золотой медальон рисуется линиями (кольцо из зерни, 12 орнаментов
«қошқар мүйіз», шаңырақ-солнце из логотипа), блик по золоту, появляется TUMAR /
Heritage Atelier, слоган «Сила предков — в благородном золоте степи», затем раскрывается
светлый фон и финальная карточка с логотипом и надписью «Ручные изделия в национальном стиле»
(по-казахски «Ұлттық нақыштағы қолдан жасалған бұйымдар»).
Звук: домбра (галоп кюя), кобыз, бубен и колокольчики, синхронно с анимацией.

- Посмотреть в браузере: `/tumar-motion.html` (крутится по кругу, кнопки ↺ Replay и 🔊 Звук).
  Параметры: `?format=story|wide|square` (1080×1920 / 1920×1080 / 1080×1080), `?lang=kz|en`.
- Готовые MP4 со звуком (30 fps, H.264 + AAC) в `public/tumar-files/`:
  `tumar-motion-story.mp4` (Reels / Stories / TikTok), `tumar-motion-wide.mp4` (YouTube, сайт),
  `tumar-motion-square.mp4` (лента Instagram); казахские версии — с `-kz` в конце имени.
- Пересобрать MP4 (нужны ffmpeg и Chromium):

  ```bash
  cd Tumar
  npm i --no-save playwright
  python3 scripts/motion-sound.py sound.wav   # звук (нужен numpy), затем:
  ffmpeg -i sound.wav -af loudnorm=I=-16:TP=-1.5 -b:a 192k public/tumar-files/tumar-motion-sound.mp3
  node scripts/render-motion.mjs story kz   # формат, язык, [fps]
  ```

## Локальная разработка

```bash
cd Tumar
npm install
POSTGRES_URL=postgres://… npm run dev   # без базы сайт работает, но заказы не сохраняются
```
